# Dice Draw

Aplicação web desenvolvida em React para realizar sorteios aleatórios de participantes.

O projeto foi criado como desafio técnico para processo seletivo de estágio, focando em:
- componentização
- organização do código
- validações
- responsividade
- experiência visual
- animações com Framer Motion

---

# Tecnologias utilizadas

- React.js
- Vite
- JavaScript
- CSS3
- Framer Motion
- React Icons
